# Saudi Market TV

تطبيق Android TV / Google TV خفيف لعرض ملخص السوق السعودي من موقع تداول السعودية الرسمي مباشرة على شاشة التلفزيون.

## الخصائص
- واجهة ملء الشاشة مناسبة للتلفزيون
- دعم الريموت وزر الرجوع
- وضع سطح المكتب داخل WebView
- تحديث تلقائي كل 5 دقائق
- إعادة تحميل عند العودة للتطبيق
- بدون صلاحيات حساسة؛ يحتاج فقط إلى الإنترنت

## بناء APK
يتم البناء تلقائيًا عبر GitHub Actions. بعد نجاح Workflow ستجد ملف APK ضمن Artifacts باسم `Saudi-Market-TV-APK`.
